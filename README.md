# Additive Manufactured Wing: Structural and Wind Tunnel Analysis

## Overview
This project focuses on the design, fabrication, structural analysis, and aerodynamic testing of an additively manufactured aircraft wing prototype. The objective was to evaluate the structural integrity and aerodynamic performance of a 3D-printed wing under realistic operating conditions.

## Objectives
- Design an aircraft wing using CAD software.
- Fabricate the wing using additive manufacturing techniques.
- Perform structural analysis to evaluate deformation and stress distribution.
- Conduct wind tunnel testing to assess aerodynamic characteristics.
- Compare experimental results with theoretical expectations.

## Tools and Software
- CATIA V5 / SolidWorks
- ANSYS Mechanical
- Wind Tunnel Testing Facility
- Additive Manufacturing (3D Printing)

## Methodology

### 1. Wing Design
- Developed the wing geometry using CAD software.
- Optimized the design for manufacturability and aerodynamic performance.

### 2. Additive Manufacturing
- Fabricated the wing prototype using 3D printing technology.
- Ensured dimensional accuracy and structural consistency.

### 3. Structural Analysis
- Imported the CAD model into ANSYS.
- Applied loading and boundary conditions.
- Evaluated:
  - Total deformation
  - Equivalent stress
  - Structural integrity

### 4. Wind Tunnel Testing
- Mounted the wing in a wind tunnel setup.
- Tested aerodynamic behavior under different flow conditions.
- Observed lift and drag characteristics.

## Results
- Successfully fabricated and tested the wing prototype.
- Structural analysis confirmed adequate strength for testing conditions.
- Wind tunnel testing provided aerodynamic performance data for evaluation.
